加法法则：(a + b) % p = (a % p + b % p) % p

减法法则：(a - b) % p = (a % p - b % p) % p

乘法法则：(a * b) % p = (a % p * b % p) % p

幂运算法则：a^b % p = ((a % p)^b) % p（除法除外）

这些法则说明了模运算在加法、减法和乘法下的行为，但除法在模运算中是特殊的，因为它不遵循同样的规则。


结合律：((a + b) % p + c) % p = (a + (b + c) % p) % p 和 ((a * b) % p * c) % p = (a * (b * c) % p) % p

交换律：(a + b) % p = (b + a) % p 和 (a * b) % p = (b * a) % p

分配律：(a + b) % p = (a % p + b % p) % p 和 ((a + b) % p * c) % p = ((a * c) % p + (b * c) % p) % p
